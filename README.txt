OJANDU RONNY PROFILE WEBSITE — IMPROVED VERSION

Files:
- index.html: semantic profile page and modules section
- styles.css: responsive styling
- script.js: navigation, live character count, form feedback, and fetch()
- modules.json: sample course module data
- Learn coding.jpg and coding inportance.jpg: original uploaded images

IMPORTANT:
1. Keep all files in the same folder.
2. Open the folder with a local web server. fetch() usually will not work if index.html is opened directly as file://.
3. If using VS Code, install/use Live Server and open index.html with it.
4. If using another editor, use its local preview/server feature.
5. To test the error handling, temporarily rename modules.json, refresh the page, and check the red error message. Rename it back afterwards.
6. The contact form currently demonstrates browser validation only. It does not send messages to an email inbox.
